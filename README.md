# Giridhar J Shenoy

Robotics engineer, manipulator control and ROS 2 systems, moving into learning-based manipulation.

- Shipped gravity-compensation hand-guiding, Jacobian TCP-jogging and joint-space PID trajectory-tracking controllers on production 6-axis arms.
- On a humanoid: led the ROS 2 architecture, OMPL constrained planning on depth point clouds, and real-time human-to-humanoid upper-body motion retargeting.
- Industrial integration: built an OPC-UA bridge to a Siemens PLC.

## Portfolio repos

Simulation, plus one result on a real arm (ur5e-teaching-controllers). Each repo has a devcontainer, CI, a one-command run, a results table regenerated by a script, and a "where it fails" section.

- [ur5e-teaching-controllers](https://github.com/giridhar-shenoy/ur5e-teaching-controllers) [![CI](https://github.com/giridhar-shenoy/ur5e-teaching-controllers/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/giridhar-shenoy/ur5e-teaching-controllers/actions/workflows/ci.yml): ros2_control effort controllers for a simulated UR5e (PID + RNEA feedforward tracking, gravity-compensated hand guiding) with Pinocchio dynamics. C++17, Gazebo.
- [pointcloud-constrained-planning](https://github.com/giridhar-shenoy/pointcloud-constrained-planning) [![CI](https://github.com/giridhar-shenoy/pointcloud-constrained-planning/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/giridhar-shenoy/pointcloud-constrained-planning/actions/workflows/ci.yml): MoveIt 2 + OMPL "keep upright" constrained planning on an octomap from a simulated RGB-D camera, with a seeded C++ benchmark. C++17, Gazebo.
- [sim-demo-to-policy](https://github.com/giridhar-shenoy/sim-demo-to-policy) [![CI](https://github.com/giridhar-shenoy/sim-demo-to-policy/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/giridhar-shenoy/sim-demo-to-policy/actions/workflows/ci.yml): MuJoCo pick-and-place on a Franka Panda: scripted demonstrations recorded as LeRobot v3.0 datasets, ACT and a small from-scratch spatial-softmax BC policy trained on a laptop CPU, and an evaluation harness with held-out seeds, a failure taxonomy and confidence intervals. Python, CPU only.

ur5e-teaching-controllers now includes a real-arm result: zero-stiffness hand guiding on an AgileX Piper-H.
